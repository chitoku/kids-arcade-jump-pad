# 別のPCで試す手順

標準の **atoms3はUSBキーボード＋Serial版**です。JUMPでSpaceを押し、LANDで離します。Serial専用はatoms3-serialを選んでください。HIDの実機・ゲームでの確認はこれからです。

1. VS CodeとPlatformIO IDE拡張機能をインストール。
2. VS Codeの「Git: Clone」で `https://github.com/chitoku/kids-arcade-jump-pad.git` を取得し、フォルダを開く。Gitがない場合は先にインストール。
3. PlatformIO → Project Tasks → atoms3 → General → Build。
4. AtomS3をUSBデータケーブルで接続。Monitorを閉じてUpload。複数台ある場合は対象を確認。
5. 接続エラーなら、画面ボタンではなくリセットボタンを約2秒長押し。内部の緑LEDが点灯したら離し、数秒後にUploadを再実行。
6. Monitorを開く。入力はログの出るターミナル内。最初の文字でログが止まり、入力内容が表示される。Enterで実行。

## 校正と確認

- 起動時は誰も乗らず、重りも載せない。自動でゼロ調整される。
- `tare`：今の無荷重状態をゼロにする。`STATUS,ZERO,...` を待つ。画面ボタンの短押しでも同じゼロ調整を開始できます。
- 既知の重りを載せて安定後、1kgなら `cal 1`。`ACK`は受信、`STATUS,COUNTS_PER_KG,...`は校正成功。
- `status`：状態を1回表示。
- `stream on` / `stream off`：連続ログの開始・停止。
- 校正値はAtomS3内に保存。同じ装置ならPCを変えても維持される。別の装置では校正が必要。

## ハードウェア

AtomS3を上下逆に取り付ける設置に合わせ、LCDは起動画面を含め180度回転して表示します。

[配線説明](wiring.md)と[配線図](wiring.svg)参照。原型AtomS3の3V3 → HX711 VCC、GND → GND、G5 → DT、G6 → SCK。3.3V対応HX711基板を使用。

80 SPS化はHX711のRATE端子によるハード設定。ソフトだけでは切り替わらない。試作機は基板加工後に約82〜83 SPSを確認済みだが、別基板で同じ場所を切るとは限らない。

まず静荷重で中央と四隅の読み・ガタつきを確認。STANDINGには8kg以上を500ms維持する必要があるので、1kgの重りではJUMP判定は作動しない。人が使う前に機械構造の安定性を確認する。

## HIDでゲームにつなぐ（0.2.0）

Upload後、ゲームを前面にしてジャンプ操作をSpaceへ割り当てます。Serial Monitorも同時使用できます。tareコマンド・センサー異常・検出状態のリセット・着地なしで1.5秒経過した場合もSpaceを解放します。

`hid off`でキー送信停止、`hid on`で再開（次のJUMPから）。設定は再起動で標準のONに戻ります。`stream off`はSerialログだけを止めます。Spaceは空中で押しっぱなしなので、ゲームやOSによってはキーリピートが起きます。まずキーの押下・解放を表示するツール等で確認してください。

## 最大重量（0.2.1）

画面下にMAX kgを常時表示。約80 SPSの各測定から最大値を保持し、荷重を外しても残る。`max reset` コマンドでリセット。画面の短押しはゼロ調整（tare）です。板だけを載せ、人や追加の重りを降ろしてから短く押し、離してください。約2.5秒のTARE表示中も無荷重を保ってください。起動時の自動tareも継続します。

最大値は電源OFF／再起動／校正成功でもクリア。tareやセンサー異常では保持。`status` でも確認可能。`ADC CLIP!` はADCの測定範囲超過が記録された印で、そのときの真の最大荷重は不明です。

最大値は測定できた荷重であり、短い衝撃ピークや各セルの偏荷重を保証するものではありません。4×50kgでも200kgまで安全とは判断できません。

## ADCの切り替え（HX711 / NAU7802）

画面ボタンを2秒長押しすると、HX711とNAU7802を切り替え、選択を保存して再起動します。ボタンを離してください。短押しはゼロ調整（tare）です。ボタンを離した時に開始するので、長押しでADCを切り替える途中にはゼロ調整しません。起動中に押されていたボタンは、一度離すまで切り替えに使いません。

ADC名は画面のSPS表示行とSerialの `status` に表示します。選択中のADCが未接続ならERRORになります。基板の差し替えは電源を切って行ってください。GPIO5/6を両ADCで共用するので、両基板を同時接続しないでください。

| AtomS3 | HX711 | NAU7802 |
|---|---|---|
| 3V3 | VCC | VIN |
| GND | GND | GND |
| G5（オレンジ） | DT / DOUT | SDA |
| G6（黄色） | SCK | SCL |

NAU7802はチャンネルA、ゲイン128、80 SPS、ブリッジ励起3.0 Vで初期化します。ロードセル側は E+ / E- / A+ / A- を同名端子へ接続し、B+ / B- は未接続です。

重量校正値はADCごとに別々に保存します。旧ファームウェアのHX711校正値も移行します。ADC切り替え後は誰も乗らず、自動ゼロ調整を待ってください。初めて使うADCでは既知の重りを載せて `cal <kg>` で重量校正してください。再起動時は選択したADCとその校正値を読み戻します。ジャンプ判定のしきい値は両ADCで共通です。
